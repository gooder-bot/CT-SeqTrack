# V41 联合模型的两组训练对照

[A 的 1/4/4/8 窗口配置](../cfgs/ct_seqtrack/41_joint_window_1448.yaml) 与 [B 的四独立候选配置](../cfgs/ct_seqtrack/41_joint_four_candidates.yaml) 使用同一个在线跟踪器。B 的四个候选指同一物理端点的四种训练起点。一条测试轨迹每帧仍只提交一个框。

| 设置 | A 和 B |
|---|---|
| 数据与优化 | KITTI Car，两个模型分别从零训练 60 轮，seed 42，batch 16，Adam，初始 LR 0.00015，第 20、40 轮各乘 0.2。两组逐批使用相同物理端点和优化步数。 |
| 定位与推理 | B0、物理时间 B1、MTP、B3/R、q0 横向点投票、局部投票、稀疏外搜及跨扫描复核均开启。q0 横向头从 E1 学习，默认从 E11 起反馈，B3 对修正后的 q0 重读支持点。 |
| 普通训练历史 | A 从单步课程逐步过渡到 1/4/4/8，窗口续步读本分支刚刚提交的状态。B 在每个端点独立初始化，分支 0 干净、1–3 分别使用受扰历史。B 的重置和增强次数随之更多。 |
| 增强与回放 | 两组共用 E57 密度匹配的连续残差增强。E1、E2 的输入、损失、更新后权重应完全相同。E3 起用同一 E2 联合模型在训练集产生的固定前态，只在同轨、同帧自己的 branch 0 回放。四类各最多 128 个，每轮合计最多 512 / 76,324 个主端点（0.67%）。每轮继续记录两组各自的自然失败。 |
| 未启用的替代方案 | 滚动更新的独立困难库、旧 uniform E10/E60 前态回放、训练中用 GT 校正已提交状态。两组使用共同前态，使模型分化后的困难样本分配保持可比。 |

## 每帧的六个推理候选

| 候选 | 对外输出和可信写入 |
|---|---|
| q0 | 观测解码给出的框，有效时可输出。横向读出融合在同一个 q0 上。 |
| B1 物理先验 | 推进已有运动状态，可输出。它没有当帧独立测量资格。 |
| 可信状态传播框 | 使用既有可信运动记录，可回退输出。它没有当帧独立测量资格。 |
| 原 R 恢复框 | 从现有恢复区域的当前点精修，有效时可输出。 |
| 局部投票框 | 从局部实际采样点估计目标中心。框内有实采点且没有另一位置的正身份竞争、冷启动也未发现第二簇时，身份弱的框仍可参与本帧输出；只有身份胜出的局部测量才可申请可信写入。 |
| 远区投票框 | 健康时默认 1 秒巡查，连续两帧弱观测后 0.2 秒巡查。首次命中只暂存位置。下一物理扫描用新点和有效模板确认，身份、几何、唯一支持点均合格后，远区框才参与本帧选框及对局部测量的身份竞争。 |

选择器在可用框中按预测 Success/Precision 的平均效用选出唯一输出。精确同分按 q0、R、局部投票、远区投票、B1、可信传播的顺序打破。选中的测量候选使用自己的唯一原始点、身份和几何质量核对写入；至少需要三个框内前景支持点。弱观测期间独立运动状态按物理时间推进。远区接管当步切断速度边，后续取得相邻可靠测量再测速。训练沿用 V41 的结构，旧版 B2 关闭。单轨 P50/P95 延迟通过[独立评估入口](V41_JOINT_SEARCH.md#运行和比较)采集。

## 在训练服务器启动

从上传后的完整项目根目录、项目 Python 环境中执行。默认复用一张已分配的可见 GPU，先训练 A，再训练 B。

```bash
bash tools/train_v41_joint_pair.sh
```

脚本打印新的 `output/v41-joint-pair-*` 目录。两份运行分别放在该目录的 `window_1448/`、`four_candidates/`，共享 `natural_e2.sqlite`。E57 增强库存在时直接读取，首次缺库时用既有 uniform E57 权重生成一次。`--devices`、`--workers` 和 `--v41_q0_lateral_warmup_epochs` 等参数会共同传给两组。环境变量 `HISTORY_BANK`、`DONOR_RUN`、`DONOR_SOURCE`、`DATA_ROOT`、`PYTHON` 和 `CUDA_VISIBLE_DEVICES` 沿用[单组准备说明](V41_JOINT_TRAINING.md)。中断后指定原目录并复用相同训练参数，有完整轮次 checkpoint 的组将续训，已完成的组会跳过。

```bash
PAIR_DIR=/path/to/original-pair bash tools/train_v41_joint_pair.sh
```

两组完成后，结果写入配对目录的 `dev_comparison.json`。比较 dev（0017–0018）末三轮平均 Success/Precision 和 E60，并报告共同可见帧的 q0 横向 MAE、逐轨差与超过 10 m 的漂移时长。对共同重现事件，统计一秒内连续三帧 IoU ≥ 0.5 的比例以及到第三帧的确认耗时，提前结束的轨迹保留在总事件分母。两种固定轮次口径均支持同一组时选用该策略。正式结果衡量整个历史重置策略，包括受扰起点数量和自递推曝光的差异。与历史 uniform 的 test 数值比较时，使用[固定轮次的 held-out test 评估命令](V41_HISTORY_TRAINING.md#gt-诊断与正式比较)。
