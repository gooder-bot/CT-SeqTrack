## 为什么第三档选择2.5e-5

直接依据是本项目已完成的 v33 正式结果。以下均为相同 mini、seed42、scratch60 预算，按固定 final60 与58/59/60均值比较：

| v33 配方 | 初始/峰值 LR | 调度 | final60 S/P | late-3 S/P |
|---|---:|---|---:|---:|
| B | 1e-4 | 20/50 | 47.5525 / 55.9179 | 46.6116 / 53.9143 |
| C | 5e-5 | 20/50 | **50.4562 / 59.2560** | **49.3738 / 58.0744** |
| D | 1.5e-4 | 20/50 | 49.3993 / 57.6214 | 48.1601 / 55.8435 |
| E | 3e-4 | 20/50，另加2000步warmup | 44.5766 / 53.8600 | 44.0835 / 53.2586 |

相同调度下，C−B 的 final S/P 为 +2.903720/+3.338074 个百分点，late-3 为 +2.762217/+4.160102 个百分点。C 是已测最佳 B0 配方，也处于已测 LR 的下边界。因此在用户限定的第三档预算内，选择2.5e-5探索 C 下方尚未测的区域；与5e-5和1e-4构成两倍间隔。7.5e-5只是在已有区间内加点，本轮优先级较低。证据见 [完整原始精度表](../artifacts/ct_checks/20260926_v33_six_recipe_review/scores.csv) 和 [六组复盘](../artifacts/ct_checks/20260926_v33_six_recipe_review/REPORT.md)。

这是一项搜索范围选择，不是“越低越好”的结论。v34 新增上下文会改变优化条件，2.5e-5也可能在固定60轮内拟合不足；所有档位均须完成原定评测。B/C的 main60 约0.281742/0.281574，几乎相同，而正式跟踪成绩相差明显，因此不按训练 total/main loss 单独挑选赢家。E 同时改变 LR 与 warmup，不能将其结果单独归因于 warmup。

两项主要研究依据仅用于说明参照与选点方法：

1. [SeqTrack3D，III-E](https://arxiv.org/html/2402.16249v1#S3.SS5) 使用 Adam、初始学习率1e-4、训练40轮。它支持把1e-4作为同任务正常档，但没有证明其对本项目60轮 mini 或 v34 最优；本轮保留已登记的60轮预算。
2. [Bergstra与Bengio，JMLR 2012，§2.4/§5](https://jmlr.org/papers/volume13/bergstra12a/bergstra12a.pdf) 在超参数实验中按对数域选择学习率。这提供倍率间隔搜索的一般方法依据，不证明2.5e-5最优，也不把本轮三个预先固定的点称为该论文的随机搜索实验。

SeqTrack半学习率尚没有本项目已完成结果；C对B的收益不能自动移植到独立参考网络。

## 比较与晋级口径

八组都固定评测58/59/60，使用正式评测完整精度与相同帧键，不选不同最佳 epoch，不用训练期 val 替代。已完成的旧 R、C、旧 v32 B0 保留为固定历史对照，新 R-normal/R-half 是额外参考实验。

- **结构主对照仍是 S-half−旧 C。** 学习率、调度和成熟窗口相同，差异对应原定上下文结构包。
- **课程增量按同 LR 的 W−S 比较。** 分别比较 normal、half、quarter；不拿 W-quarter−S-normal 当成课程效应。课程同时改变前九轮递推进入时机，不能只归因成熟窗口。
- **LR 效应在各自结构内比较。** S的三档、W的三档及SeqTrack正常/半档各自形成对照。不同LR取得最好成绩，不等于证明每个上下文字段单独有效。
- **新 R-normal/R-half 额外报告。** 新参考若更强，必须明确报告与其差距；不靠更弱的新参考降低原登记门槛，也不因单次参考重跑改变旧 R/C 阈值。

每个 S/W 候选须同时满足原两道四项硬门：

| 固定门槛 | final60 S/P | late-3 S/P |
|---|---:|---:|
| 总体不低于旧 R | 51.823851 / 61.341356 | 51.884391 / 61.966448 |
| 31条曾移动轨迹全程不低于旧 C | 39.912481 / 45.711568 | 38.479199 / 44.679097 |

表内仅展示六位小数；实际判断读取原始精度。移动集合固定为轨迹中曾有相邻 GT XY 位移≥0.15m，共657个预测帧，不含初始化。弱观测 raw0/1–2/3–9/≥10、首预测缺测、曾移动轨迹低位移片段、同状态 coarse→fine、失跟与质量诊断沿用原协议的共同分组。

在满足全部硬门的候选中按 final Success、再 Precision 排序；总体通过但移动守底失败，仍留在 B0。八组结果中的局部切片改善不代替硬门。六个 S/W 候选均不达标时，先做固定输入的历史/语义分支依赖检查，再决定下一项改动，不自动追加更多 LR 或模块。本轮仍是 mini 单 seed 配方选择，不能据此宣称稳定普适收益。
