## 结论

本实验完整通过运行完整性检查，并足以固定后续 B0 训练协议为：

```yaml
ct_recursive_reseed_enabled: true
ct_b0_rng_shift_control: false
```

对应 arm 为 `reseed1_rngshift0`。周期性 re-seed 是训练 curriculum：按
`[1, 2, 4, 8]` 视野用 GT 初始化历史，视野内部仍写入 observation；验证与部署
始终是闭环递归，不能把它描述为推理时使用 GT。RNG-shift 只是在 observation
forward 后额外消耗一次全局随机数，不携带方法语义，正式实验永久关闭。

`reseed1_rngshift1` 虽然 seed42 数值最高，但选择它等同于按一个偶然随机训练轨迹
调参，不能形成可辩护的论文协议。

- 四臂均为 scratch：没有 `checkpoint` 或 `init_checkpoint`。
- 四臂使用同一 tracked-clean commit；运行时只有日志等未跟踪文件。
- 除 experiment/path 元数据及注册的 reseed、RNG-shift 因子外，resolved config
  完全相同；数据 selection SHA256 均为
  `7b4e9cca2038e7cb6c9483943b627af18e433c16e13b52bcd1478b14a6a25100`。
- 每臂均完成 epoch 60、12,780 个 B0 optimizer step、12 次验证；final checkpoint
  为 `epoch=59`、`global_step=12780`、`ct_epoch_boundary_complete=true`，最终学习率
  为 `1e-6`。
- TensorBoard 的 `success/test`、`precision/test` 实际评估 mini_train 的 atomic
  `dev` partition，共 37 个 tracklets；它不是 `mini_val`。因此不能与历史
  mini_val 数字直接比较。
- B2 未启用，所有 acquisition 计数为零是预期行为，不是数据缺失。

## 可以与不可以得出的结论

可以固定：

- 当前 online candidate0-only 训练在 60-epoch 预算下需要有限视野 re-seed；完全
  无 re-seed 会产生明显的闭环漂移和很大的训练回归损失。
- 后续所有 arm 应使用相同 re-seed curriculum，并关闭诊断 RNG-shift。
- 单 seed 对全局随机流很敏感，因此共享 prefix hash 与隔离 RNG 是消融有效性的
  硬门槛。

不能声称：

- re-seed 是论文创新或带来可泛化涨点；它只是开发集选择出的训练协议。
- 任一 cell 优于历史 B0；历史结果多数来自 `mini_val`、不同数据量、sampler、
  optimizer-step 数和代码 commit，不能直接归因。
- seed42 的差异具有统计稳定性，或 CT 的 B1/B2/B3 已经有效。

## 后续固定顺序

1. 不再修改 B0 模型、online sampler、candidate0、loss、optimizer、scheduler、
   rollout horizons 或本报告冻结的两个开关；任何修改都使本次选择失效。
2. 先完成代码验收项，再运行无 checkpoint、完整 train/dev tracklets 的 acquisition
   preflight；未达到 100 个 target-bearing candidate0 rows 或 50% retention 时只改
   support 几何，并回到 B0 冻结检查。
3. preflight 通过后，B0、B1-only、Full-B3、Full 各自重新 scratch 做 3–5 epoch
   kill test；本次四个 checkpoint 全部只作协议证据，禁止初始化后续 arm。
4. kill test 必须核对 init、step1、step100、epoch-end 的共享 B0/B1/B2 hash；任何
   应共享的 prefix 不一致则整组作废。
5. 通过后四臂再次 scratch 跑 seed42 60 epoch并统一使用 final epoch；只有 B2
   headroom、B3 calibration 和 Success/Precision 双改善全部通过，才进入机制对照
   与多 seed。
