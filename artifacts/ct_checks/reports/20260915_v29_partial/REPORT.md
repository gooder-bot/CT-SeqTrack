**2．数据划分和统计口径**

三组记录相同350个train_track场景、202,750个目标帧、11,462条轨迹；官方val为150场景、64,159目标帧、3,660轨迹，场景交集为0。四候选展开811,000行，batch16自然drop_last后810,992行、50,687次更新，未发现人为少跑或重复补齐。Full每轮另有191,288个机制预测端点、11,956个机制事务，与总帧数减轨迹初始化帧一致。

内部17场景策略拟合与18场景诊断都包含在350个训练场景中。它们适合训练内部分析，不能称为独立泛化验证。provenance的dirty标志对应已记录的旧artifact删除及未跟踪日志目录，未列出生产源码改动，不能仅凭dirty推断三个模型代码不同。

本次诊断序列检查未见重复step、倒序或非有限数；456个相关事件文件长度边界完整，未做CRC或checkpoint哈希门禁。现有记录没有此前二维NLL、浮点CUDA cumsum的主错误；这只说明已同步部分跑通，不能保证未执行的验证、评测路径没有错误。

发现一个**确实需要澄清的指标接口问题**：

| 字段 | 真实分母/含义 |
|---|---|
| epoch `row_recall` | 768已经含目标的行中，256是否仍保留至少一个目标点 |
| epoch `point_recall` | 最终256目标点数 / 完整原始extension support目标点数 |
| step `ct_acquisition_point_recall` | 最终256目标点数 / 768输入目标点数 |
| sampled presence | 最终256中至少一个真实目标点；不保证获胜共识含目标 |
| sampled help/harm | 同状态bounded相对observation的即时平均S/P效用正/负 |

同名point_recall跨层级分母不同。后续应分别命名为raw-support→256与768→256，保留各阶段计数；无分母时标记未定义，不能把0混入条件均值。B0 acquisition全零是B2未启用，不能解释为失败；targetness balance是跨epoch累计，不是单轮计数。

**3．B1/B2：取得新增目标的事务少，但选择器已有作用**

| 已完成第2轮 | Full-CfC | Full-GRU | 口径 |
|---|---:|---:|---|
| 768含新增目标的端点 | 10,058 / 191,288，5.26% | 9,893 / 191,288，5.17% | 全量机制端点 |
| 768有目标后256仍有目标 | 100% | 100% | 条件行保留率 |
| raw extension→256目标点保留 | 365,069 / 669,005，54.57% | 359,542 / 665,597，54.02% | 全量点数，跨两级采样 |
| 768→256目标点保留 | 76.82% | 76.97% | 241个日志批次，先加点数再除 |
| 含目标批的目标密度富集 | 1.236倍 | 1.242倍 | 条件抽样批均值，中位均为1 |

第1轮768含目标行只有7,071/7,222，第2轮增加；并非完全没有学习。当前证据支持保留768→256选择器，不能把累计约45%的点减少全部归因于它，也不能因行保留100%就认定几何信息足够。

**5%左右不意味着95%获取失败。** 其余端点可能已被B0 crop覆盖全部目标，也可能全局没有可见新增点，或目标超出合法范围；当前缺少逐帧的全局novel/最大可达分母，不能区分它们的实际比例。需要沿同一端点记录：全局新增目标 → 最大合法范围可达 → 实际support → 768 → 256 → 获胜共识中的目标。各阶段同时统计unique目标点和至少一个目标的事件数。

B1第2轮抽样margin均值CfC为(2.1057, 1.00015)m、GRU为(2.0944, 1.00016)m，相对(2,1)m下界，横向几乎不扩张。9月14日当前生产几何的静止Car反例显示，初始support可能完全落在B0 raw crop内部，按正确ID差集得到零新增点；而最大横向范围只比该B0 crop边界多0.75m。这是已复现的几何可能性，尚非真实数据发生率。

更合理的候选实验是：把有限新增带相对**实际B0 crop投影边界**定义，或对因果可观测的低质量状态提供有限备用带；保持point budget、ID差集和GT不可见性。获取margin监督再按“存在可达新增需求/无需求”拆分归约，保留无需求成本。全局稀有正例不自动证明网络会坍缩，必须检查条件需求比例与梯度贡献，不能直接无限扩大搜索。

B2还有比selector容量更具体的共识问题：当前seed按单点targetness选最多3个，孤立高分背景可挤掉真实目标簇；模式排名同时乘targetness质量和未加权点数比例，会重复奖励密集背景。已保存的生产函数反例中，5个高质量目标vote可输给100个低质量背景vote。先分别对照“去除重复点数因子”和“按局部加权支持选seed”，沿用K=3、NMS及原预算。**真实发生频率未测量，不承诺修改后涨分。**

| 第2轮抽样结构合法候选 | Full-CfC | Full-GRU |
|---|---:|---:|
| 样本数 | 665 | 682 |
| 最终256含目标 | 103，15.49% | 104，15.25% |

这些是训练中变化权重、混合行为策略上的抽样合法候选，**不是官方S/P下降15分，也不是部署accepted动作的有害率**。第2轮候选均值比第1轮更负，但访问状态也在变，不能断言固定模型性能退化。presence判别有进展，有益动作稀缺是另一件事。约85%的合法候选未含真实目标，保留这些负例是必要的；不能以GT/presence硬门删掉负例美化数据。

H3第2轮每臂scheduled5,977、hash抽样619、未抽样5,358；真正executed/valid仅205/207，有效事件的两步回退续推增益也为负。它提示有害干预可能持续，但H3只是一种抽样单次干预诊断，不能当成长程策略评测。

当前B3单步XY半径在dt=.5秒时为.75m，配合即时S/P目标，适合局部纠偏。距离超过2.75m时单步无法进入2m Precision范围；若修正前后IoU也均为零，一次几何上正确的小步可能仍没有正H1标签。先量化“中心误差改善但H1=0”的比例、raw→bounded限幅饱和率及获胜共识身份，再决定连续几何/未来恢复目标。直接放宽半径或把H3静默加回loss没有依据。

另外，按never轨迹上的action mask去重阈值，不保证它们在接受动作后的闭环等价；该离线策略拟合问题可先用现有权重在内部17场景作数值阈值去重/小范围闭环对照，18场景锁定诊断。官方150场景不拟合阈值，不选后端或best epoch。

来源：[抽样合法动作表](validation/sampled_legal_action_rates.csv)、[H3及指标范围](validation/REPORT.md)、[B3接口定位](method/REPORT.md)。

**5．B0仍有数据语义问题，不能用seg高准确率证明健康**

v29已落实帧布局修正、Transformer mask、1/2点真实采样、预测历史与GT监督拆分、accepted递归提交。不要把这些再次列为尚未实施的问题。

仍存在的漏洞是：Seg/BC等继承loss未使用真实点有效性，补零坐标落在GT框内时可成为虚假前景。9月14日真实sampler/host合成案例中，当前帧0个点，却产生1024个前景槽，Seg和BC输出梯度均非零。它是代码确认的监督问题；本次日志没有逐样本空点比例，不能推算影响了多少训练样本或得分。

最小后续修改应先只屏蔽不存在的点/帧：CE用有效类权重和作分母，BC/ref按各自有效语义归约，全空测量项给可反传零值，保留框/运动监督；不跳端点、不GT重置。1/2点重复槽来自真实点，不与空槽混为一谈。继续使用已有确定性NLL路径。

注意力前的Seg/Mini PointNet全局池化及普通BN仍可能受缺失历史槽影响。9月14日同mask但改变无效槽的反例有训练输出变化，但不能因此声称当前每个缺失帧都会造成同样幅度误差。有效池化/全空分支与BN统计应独立验证，简单置零或仅Transformer mask不能排除全部影响。

B0当前最多3步roll-in，Full机制访问更长的accepted轨迹；这符合共享B0独立训练的合同，但短窗口未覆盖长时间漂移。第2轮机制输入上的`loss_b0_transaction`诊断均值为8.8778/9.0187，明显不同于共享观测流，但它不加入实际机制总loss，也不回传B0；两类输入及历史监督口径不完全相同，不能将其相除当作曝光偏差的因果量，也不能误报为观测训练loss崩坏。先比较teacher/roll-in/闭环的anchor误差、0/1/2/3+真实点、有效历史数和长空段；有覆盖缺口时再对少量样本延长窗口，避免无依据增加全量递归成本。

**6．方法与数据的契合度，以及下一步顺序**

保留序列B0有依据：[SeqTrack3D](https://arxiv.org/abs/2402.16249)本来就融合历史点云与框来处理稀疏观测；[M²-Track](https://arxiv.org/abs/2203.01730)也将运动定位与后续几何修正分开。这些研究支持模块职责，并不证明本项目的获取范围、共识公式或效用目标已最优。

B1本次抽样物理位移RMSE：CfC 1.2257m，对应kinematic 1.3408m；GRU 1.2556m，对应1.3729m，各自约改善8.6%，因此不支持推翻运动先验。该指标监督相邻GT物理位移，与绝对anchor漂移不同。统计50%椭圆却覆盖约91%的有效样本，80%约93%、95%约94.5%，提示主体误差与尾部的不确定性拟合需要分桶；不能一律缩sigma。sigma与acquisition margin是独立头，过覆盖与margin贴下界可以同时出现。

机制query dt的抽样批均值约0.5028秒，当前并未证明大范围不规则采样。不能把CfC的连续时间形式直接当作相对GRU优势；主任务需要相同完整预算的闭环分数，时间适应性需另行登记间隔控制实验。当前后端小差异还混有不同机制递归状态，不适合选胜者。

建议当前运行先获得**同第5轮的首个完整官方验证**，同时利用已有第2轮checkpoint做训练内部的逐帧诊断与同权重observation / bounded-always / 拟合策略闭环对照。第5轮只用于中途健康诊断，正式结果仍固定final60及58/59/60。现在不必等60轮才检查已经明确的监督问题，也不宜仅凭训练loss和抽样动作率立即宣布三组失败。

后续方法修改按独立版本与小对照推进：

1. 先修无效测量监督，拆清真实稀疏/补槽统计；再验证注意力前填充影响。
2. 补全可达证据分母，核查margin需求标签；分别验证共识seed与排名的小修改。保留选择器、ID差集、memory/Seg64 detach及host单点提交职责。
3. 同状态联结presence、共识身份、raw、bounded、q、accepted与误差变化，确认有害动作来源，再调整获取或动作目标。
4. 单独检查不确定性、长递归覆盖与策略闭环阈值；不将方法变更作为“数值等价性能补丁”混入现有run。

**目前最缺的是带正确分母的状态—证据—动作关联数据，而不是更多总loss曲线。** 现有证据支持“运动在学、选择有富集、判别在学”，同时明确暴露“有效新增目标事务少、合法动作多数有害、无效槽监督仍存在”。各问题对最终S/P的贡献及修改收益，需要上述固定权重诊断和后续实验验证。
